# Suivi New Biz

Prototype d'outil de suivi de prospection (tableau, pipeline, relances, journal d'échanges).

- Ouvrir la page, puis « Importer l'Excel » pour charger un fichier de suivi.
- Les données importées restent dans le navigateur de l'utilisateur. Rien n'est envoyé sur un serveur.
- La page contient uniquement des données d'exemple fictives.

Ne jamais déposer de fichier de données réelles dans ce dépôt.
